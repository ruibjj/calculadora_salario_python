\# 💰 Calculadora de Salário em Python



Projeto em Python que calcula o saldo mensal de um usuário com base no salário

e nos gastos mensais.



\## 🧠 Funcionalidades

\- Entrada de dados pelo usuário

\- Cálculo do saldo mensal

\- Verificação de saldo positivo ou negativo

\- Formatação de valores no padrão brasileiro (R$ 4.300,00)



\## 🛠 Tecnologias

\- Python 3



\## ▶️ Como executar

No terminal, dentro da pasta do projeto:



```bash

python calculadora\_salario.py
